# ☕ Coffee Shop Sales Analysis

## 📊 Project Overview

This project analyzes coffee shop sales data using Microsoft Excel to identify sales trends, customer preferences, and overall business performance.

The analysis helps understand which products perform best, when sales are highest, and how revenue is distributed across different categories.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Excel Formulas
- Data Cleaning
- Charts & Data Visualization

## 🔍 Analysis Performed

- Cleaned and organized the sales dataset
- Analyzed total sales and revenue
- Identified top-selling products
- Analyzed sales by product category
- Compared sales performance across different time periods
- Created Pivot Tables for data analysis
- Created charts to visualize important business insights

## 📈 Key Insights

- Identified the highest-performing products
- Analyzed customer purchasing patterns
- Identified sales trends across different periods
- Compared product categories based on sales performance
- Highlighted areas that can help improve business decisions

## 📁 Project Files

- `Coffee Shop Sales.xlsx` — Main Excel analysis file

## 🎯 Objective

The objective of this project is to demonstrate practical Excel data analysis skills and convert raw sales data into meaningful business insights.
